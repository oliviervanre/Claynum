# Claynum — site vitrine

Code source du site vitrine [claynum.fr](https://claynum.fr), consacré à une démarche d'appui numérique pragmatique pour les petites structures et associations.

Claynum est actuellement un **projet personnel expérimental, sans activité commerciale rémunérée**. Le site précise son statut et les conditions des accompagnements envisagés.

## Structure

- `index.html` : contenu de la page, interactions simples et suivi d'audience.
- `styles.css` : présentation et mise en page responsive.
- `assets/` : éléments graphiques, dont le logo.

Le site est statique, sans framework ni étape de compilation. Il utilise GoatCounter pour les statistiques de fréquentation.

## Consulter en local

Ouvrir `index.html` dans un navigateur. Aucun serveur applicatif ni installation de dépendances n'est nécessaire pour consulter la page.

## Publication

Le site est hébergé chez **Infomaniak**. Les modifications sont versionnées dans ce dépôt GitHub, puis les fichiers modifiés sont **transférés manuellement** sur l'hébergement.

La mise à jour de GitHub ne publie donc pas automatiquement le site en ligne. Après chaque transfert, vérifier le rendu sur [claynum.fr](https://claynum.fr).
